We have crossed this country more times than we can count, and never once in a straight line. So this is not a trip we took. It is the one we would drive if we started again tomorrow, built out of the places we would actually send you to.

Most of these we have been to. A few we have not, and those say so plainly — we would rather tell you a place is worth your time on someone else's word than pretend we have stood there ourselves.
